Modern, responsive web application built with **React**, **Vite**, **Tailwind CSS**, and **Supabase** for **Elite Gym** in Sagar, Madhya Pradesh.

## 🎨 Design & Features
- **Purple & White Aesthetic**: Clean, modern boutique fitness theme with royal purple accents and high-contrast typography.
- **Interactive Workout Routine Finder**: 4-step assessment in a modern Bento grid layout (Goal, Fitness level, Sagar batch, Guidance preference) generating customized splits and calorie recommendations.
- **Google Review Summary Card**: Replica of the 4.7★ Google review card with verified member ratings and live review submissions.
- **Health Tools**: Interactive BMI and TDEE calorie calculator.
- **Digital Pass**: Free 1-Day VIP Trial Pass generator with unique Pass ID (`ELT-SGR-XXXX`).
- **Live Shift Status Clock**: Real-time batch indicator tracking opening hours.
- **Supabase Cloud Backend**: All contact inquiries, trial passes, quiz plans, and membership leads automatically synchronize with Supabase Postgres database.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation
```bash
# Clone the repository
git clone https://github.com/buildwelldevelops-arch/Elite-gym.git
cd Elite-gym

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
